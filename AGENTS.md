# Release publishing

- Upload the player mod ZIP and its checksums for a release.
- Do not manually upload source ZIP files to Nexus Mods or GitHub release assets. Link the public repository or immutable release tag for source and build instructions instead. GitHub's automatically generated source archives can remain available.
- Keep locally prepared source ZIPs and reproducibility records local; their existence is not permission to publish them.
- If Nexus quarantines a file, report its status. Do not repackage it to evade the checks or contact support without the user's authorization.
- Apply this policy to release notes and download descriptions so they do not advertise a separately uploaded source ZIP.
